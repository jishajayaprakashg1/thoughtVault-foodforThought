# Playwright
* Why playwright?
  - open source
  - supports multiple languages: .net, java, python, javascript, typescript
  - cross platform support: windows, mac, linux
  - multiple browser support: chromium, webkit, firefox
  - can run from local or CI in headless or headed mode

* Top features
  - auto wait and retry
  - inbuilt codegen tool
  - reporting using traceviewer, debuuging using playwright inspector
  - parallel execution using multiple users, muliple origin and multiple browsers
  - isolated browser context
